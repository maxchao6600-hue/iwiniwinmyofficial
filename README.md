# IWIN Malaysia Official Partner Website

Production-ready Next.js information website for IWIN Malaysia Official Partner positioning.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- English / Bahasa Malaysia / Simplified Chinese

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Notes

- External register/login/agent destinations are centralized in `lib/constants/site.ts`.
- This site provides information and guides; registration/login may open an external platform.
